## 开始使用

打开软件后跟随内置引导，连接自己的 AI 工具账号，再选中文字试一次优化。

0.4.17：设置页焕新（按钮与卡片统一，“AI 连接”分步完成，“通用设置”集中语言、快捷键与结果显示方式，标题栏改为深色）；操作失败时自动生成诊断报告；悬浮窗新版本提示移到标题栏，设置窗口在前台时暂不置顶；Windows 首次安装选择的语言作为初始界面语言。0.4.16 起：应用内一键更新，Mac 升级保留辅助功能权限。0.4.15 起：内置安装与 AI CLI 调用自动使用系统代理，“测试当前模型”更准确，结果框内可再次优化，新增诊断报告。

0.4.11 已支持旧内置模型预设精简与恢复；自建或改过的配置保留。在模型页可“恢复升级前预设”。

当前为测试版。Windows 未进行发布者代码签名，首次下载或运行可能被系统拦截；先核实来源与文件校验，再按安装帮助处理。Windows 0.4.17 已在隔离 Windows 11 实测安装、安装语言联动与重装保留配置（应用内更新机制已于 0.4.16 实测）；另一台 Windows 的真实账号慢请求仍需现场复测。Mac 0.4.17 使用自建证书签名，未经 Apple 公证，首次打开可能被系统拦截。Mac 0.4.17 已在 Mac M 系列实测从 0.4.16 覆盖升级保留配置与辅助功能权限（无需重新授权）；其他输入应用和 macOS 版本尚未逐一验证。首次使用或更新后，请按应用内提示检查辅助功能权限。

What Localtype does

Localtype turns selected text into clearer AI instructions. Select a draft in another application, optimize it, review the result, then copy it or replace the selection. You decide when and where to send the result.

It uses your installed Codex, Claude Code or Google Antigravity (AGY) CLI, or an API key, together with your account or model service. AI access, usage limits and charges depend on that service. Localtype does not include speech input. You can use text produced by a separate dictation tool.

This guide works offline. Installing AI tools and using network-backed models require a connection. Text capture, replacement and undo depend on the host application; test with disposable text first.

Choose English in the application's language setting if needed. Automatic language uses Chinese on Chinese systems and English on other systems. Your own text, template bodies, paths, model IDs and history are preserved when you change language.

New optimized results follow the interface language by default: English in the English interface and Simplified Chinese in the Chinese interface. An output language explicitly requested in your draft takes priority. Switching languages does not translate existing results or history.

1. Check your computer and package

Open Apple menu > About This Mac. Use the Apple Silicon package for an Apple M-series chip, or the Intel package for an Intel processor.

Package platform: macOS-AppleSilicon. Installer: Localtype-0.5.1-macOS-AppleSilicon.dmg. Compare the installer's SHA-256 with SHA256SUMS.txt from your trusted distributor. A matching checksum checks file integrity; it does not by itself establish that the distributor is trustworthy.

2. Extract the ZIP before installing

Double-click the ZIP in Downloads, then open the extracted folder and its DMG.

Keep the README and checksum list with the package. Do not run the installer from the ZIP preview.

3. Copy Localtype to Applications

Open the DMG and drag Localtype to Applications. Wait for the copy to finish. For an update, quit the existing app first and choose Replace when Finder asks. Open Localtype from Applications.

4. Open Localtype

If macOS blocks the app, choose Cancel or Done first; do not choose Move to Trash. Follow the route matching the exact message.

Developer cannot be verified · App is damaged · App opened: enable permissions

Developer cannot be verified / cannot check for malicious software

Only approve a package you trust after checking its source and SHA-256. Close the alert, then open System Settings > Privacy & Security, find Localtype and choose Open Anyway. Confirm the system prompt. If the button is missing, try opening the app once from Applications, then return to Privacy & Security.

Stop if integrity or malware checks fail

If the checksum does not match, the file is genuinely damaged, or macOS says it will harm your computer, stop and contact the distributor. Manual approval does not sign or notarize the app.

Apple: safely open apps on your Mac

“Localtype is damaged and can't be opened”

Choose Cancel or Done. Continue only for a trusted project test package with a matching SHA-256, after confirming that quarantine is the cause. This command cannot repair damaged or incomplete files. If macOS reports malware or says the app will harm your computer, stop.

Press Command+Space, search for Terminal, and press Return. Confirm that Localtype is in Applications, then use the application-scoped command below.

Show the quarantine command

Remove quarantine from this trusted app only

Copy, paste in Terminal with Command+V, then press Return

/usr/bin/xattr -dr com.apple.quarantine "/Applications/Localtype.app" && /usr/bin/open "/Applications/Localtype.app"
Still cannot open it?

If Terminal says the app cannot be found, check Applications. If the damaged warning remains, stop and download the package again rather than repeatedly running the command. The guide cannot run commands or change system settings for you.

Allow text capture and replacement on Mac

In Help & feedback, open the permission settings. In System Settings > Privacy & Security > Accessibility, enable Localtype. If it is missing, use + to add Localtype from Applications. Return to the app, wait for the permission check, then restart when prompted. Test selection, optimization and replacement with disposable text.

Permissions stopped working after an update

Quit and restart Localtype once first. If it works, you do not need to authorize it again. If it still fails, Localtype shows a permission guide card (or choose Re-authorize in Help & feedback): click Re-authorize, turn on Localtype in System Settings, then restart when prompted. Only if the card never detects access, remove the stale Localtype entry from Accessibility, add the updated app from Applications and enable it. Removing this permission entry does not delete the app or your user data.

Connect one AI tool

Open Settings > AI connection from the floating window's gear. Find an installed AI CLI and select the candidate you want. If none is installed, use Install Codex CLI, Install AGY CLI or Install Claude Code CLI. Open the official installation guide beside the button if you need platform instructions. Log in, check the status, save the model profile and make it active.

Use one route; you do not need to install both, or you can skip the CLI and connect with an API key (Route C below). Existing CLI installations and account settings can be reused. Finding or installing a CLI does not reset your saved Localtype profiles or clear CLI credentials.

Automatic installation failed

Read the reason beside the button and retry only after addressing it. Open the troubleshooting details and copy them for feedback. You can open or copy the official installation URL. Use the manual fallback below only when needed, rather than overwriting a working installation.

Route C: connect with an API key

Choose this route if you have no Codex, AGY or Claude subscription, do not want to install a CLI, or prefer pay-as-you-go billing. Use one of routes A, B, C or D.

Steps: Settings > AI connection > New profile > set Connection type to API key > choose a provider and region (China or International) > click Get an API key and create a key on the provider's site > paste it into API key and Save > choose a model, or click Get model list and pick one > Test current model > Set as active. OpenAI, Gemini, Claude, DeepSeek, Qwen, Kimi, OpenRouter, SiliconFlow and custom OpenAI-compatible endpoints are supported.

Key storage: the key is stored as plain text in api-keys.json inside the Localtype data folder, and is not written to logs, history or diagnostic reports. Do not share or upload that folder. The provider bills your usage; a test call may also cost a small amount.

Network: each profile can follow the system proxy (default), connect directly, or use a specified HTTP proxy (http://host:port). Providers in China usually work directly. OpenAI, Claude and Gemini do not serve mainland China, Hong Kong and some other regions, so use a proxy or choose a provider in China. A local or LAN Ollama server connects directly.

Invalid key

A 401 or invalid-key message: copy the whole key again without extra spaces, and make sure it belongs to the selected provider and region (China and International keys differ).

Region not supported

A region or 403 message means the provider does not serve your region. Use a specified proxy in the profile's Network setting, or choose a provider in China.

Balance or rate limit

"Balance or quota insufficient": top up or check the usage cap in the provider's console. "Too many requests": wait and retry; Localtype retries once automatically. "Provider busy": try again later.

Model not found

Click Get model list and pick again, or check the model ID spelling and whether your account can use it.

Connection timed out

Check the network and proxy. Try Direct for providers in China; for overseas providers make sure the proxy app is running.

Certificate error

Usually caused by a company network or proxy app intercepting HTTPS. Turn off the interception or switch networks; do not trust a certificate of unknown origin.

Route D: use Claude Code (with a Claude subscription)

Choose this route if you already have a Claude subscription or an Anthropic account. Use one of routes A, B, C or D.

Steps: Settings > AI connection > New profile > set Connection type to Claude Code > click Install Claude Code CLI (one-click install inside Localtype) > click Log in, which opens a terminal and runs claude auth login; finish signing in in the browser > click Check sign-in (equivalent to claude auth status) > choose the model source: follow the CLI, or pick sonnet, opus, haiku or fable > Test current model > Set as active.

Localtype calls Claude Code read-only with all tools disabled, so it does not read or write your files. If the ANTHROPIC_API_KEY environment variable is set, Claude Code uses that key and bills by usage instead. Claude Code is not available in some regions. Claude Code 2.1.259 or later is required; for an older version, run claude update.

Find the CLI and resolve path problems

After installation, reopen the terminal and repeat the version check. In AI connection, find installed tools again and choose the actual executable path. Do not replace a working installation just because a stale terminal cannot find it.

Download, login or connection still fails

Check your network, proxy and the selected account. Localtype uses your system proxy automatically (for example a proxy app's “System Proxy” mode); if it still fails, make sure the proxy app is running. Restart Localtype after changing proxy settings. Share diagnostic details without passwords, tokens or login files.

Save and activate your model profile

By default Localtype inherits the CLI's model and reasoning settings. Save the profile, then set it as current. Reopen AI connection to check that the executable path and inheritance choices remain saved.

An upgrade simplifies unchanged built-in presets to Antigravity and Codex while retaining profiles you created or edited. If needed, use the model page's option to restore pre-upgrade presets and confirm it; conflicting old profiles are restored as separate copies.

1. Select a draft

Paste this fictional sample into a blank text document, then explicitly select the whole paragraph. On Mac, Sublime also requires an active selection.

Practice text

Research a shared task app for two people to manage groceries, chores and travel preparation. Compare phone and desktop support, explain the limits of the free plans, and recommend an option with links to original sources.
No text was captured

Select the text again in a plain text editor. On Mac, verify Accessibility permissions. If it still fails, report the host application's name and the error, with private text removed.

2. Optimize and review

Keep the original text selected and click Optimize in the floating window. Cancel stops the current request. Review the preview for missing constraints or added assumptions before using it.

Timeout, model access or network failure

Check the chosen CLI, account and model in its own terminal. Confirm that the account whose quota you checked is the one Localtype uses. Select the original text again before retrying. Unknown login status needs diagnosis; it is not proof that you are signed in.

3. Copy the result

Click Copy in the preview, switch to your AI tool and press Command+V. Review it, then send it yourself. Choose any research or execution mode in the receiving tool separately.

More ways to use Localtype

The following features are optional. Start with copying until you know how your editor handles selection and simulated input.

Replace the selected text

After selecting text and optimizing it, click Replace in the preview. Keep the source window and original text unchanged while the request runs. Verify the result in the source app.

The result was appended instead

Stop clicking Replace. Use Copy to keep the result, then report the host application and what happened. Use disposable text for further testing.

Undo a replacement

Use Undo in the same preview after replacement. Localtype stops before writing if it cannot verify the current text. If it says undo was sent but the outcome could not be confirmed, inspect the source app and, if needed, use that app's own undo. Do not repeatedly overwrite the text.

Templates, modes and language

Use the left and right arrows in the floating window to change templates. Edit templates and their order in Settings > Prompt templates. Your own template bodies are not automatically translated when you change the interface language.

Standard, Plan and Goal are single-pass prompt optimization modes. Plan structures steps and checks; Goal emphasizes the authorized outcome and completion conditions. These modes change the output prompt. They do not automatically switch the receiving AI harness's mode, run the task or grant additional permission.

Optional: Skill context

Choose Skill-assisted optimization when you want to refer to an existing Skill (an instruction file). In your draft, write $skill-name, the full path of a SKILL.md file (on Windows C:\...\SKILL.md; on Mac /Users/.../SKILL.md or ~/.claude/skills/.../SKILL.md), or a Markdown link that points to a SKILL.md file, then write your request.

When you refer to a Skill by name, Localtype searches in this order: ~/.codex/skills, ~/.agents/skills, ~/.claude/skills, ~/.gemini/skills, ~/.qwen/skills, ~/.kimi/skills, the Skills bundled with Antigravity, then the Claude plugin cache and the Codex plugin cache. If names collide, the earlier location wins. Skills installed through directory junctions or symbolic links can be read too.

Limits and behavior: at most 3 Skills per request, with a combined body of about 96,000 characters. Skills are loaded read-only as context; Localtype never executes them. With an API connection, the Skill body is sent to the selected provider with your request and counts toward usage. With a local Ollama model, watch the context length (OLLAMA_CONTEXT_LENGTH); a value that is too small truncates the input.

Example: refer to a Skill by name

Use $my-skill as context to improve this request: ...

Example: replace this path first

Use [My Skill](/Users/your-name/.codex/skills/my-skill/SKILL.md) as context to improve this request: ...
The Skill cannot be found

Check the spelling of the name, or that the referenced file exists (names are searched in the order above). You can also write the full path, or return to General optimization and select your draft again.

Local history and privacy

Open Settings > History to enable local saving and view saved results. Content from before saving was enabled cannot be recovered retroactively. Review your history retention settings. Local history is separate from text sent to your configured AI service; offline storage does not make model requests offline.

Upgrade while keeping your settings

From 0.4.16, Localtype checks the public download site for new versions (at most once a day; turn this off in Help & feedback > Software update). When a new version is available, review the release notes and choose Update now: Localtype downloads it, verifies its signature, installs it and restarts. Settings, templates, history and Mac Accessibility access are kept. You can also choose Check for updates there at any time.

To upgrade manually, finish or cancel an optimization, then quit Localtype from its tray menu. Install the newer package for the same platform. On Windows follow the upgrade wizard; keep any option to delete application data unchecked. On Mac replace the app in Applications. You do not need to delete your configuration, history or CLI account files.

Reopen the app and check the language, current model, templates and history. Existing guidance completion state is retained; use Help & feedback to reopen the step-by-step guide. On Mac, restart once before trying the permission repair steps. If you must roll back, use the previous trusted installer and preserve user data rather than clearing it.

Uninstall the application

Quit Localtype, then move Localtype from Applications to Trash. Removing the app and deleting user data are separate operations. Keep configuration and history if you plan to reinstall; do not delete CLI account files or unrelated applications.

Localtype and your AI CLI are separate installations. Uninstalling Localtype does not mean your Codex, Claude Code or AGY account has been signed out or its installation removed. Manage those tools with their own instructions.

Example: a rough idea becomes a reviewable task

Fictional illustration, not a real model result: “Fix the mobile booking button; it is hidden by the bottom bar. Sometimes submitting twice creates two bookings. Keep the desktop layout working.”

A clearer request: “Investigate the mobile booking button being covered by bottom navigation. Preserve the working desktop layout. Reproduce the missing submission feedback and possible duplicate bookings before choosing a fix. Verify mobile and desktop success, rapid clicks, slow network and failure cases. Report the cause, changes, tests and remaining gaps.”

Optimization should retain uncertainty and your constraints. It cannot prove a diagnosis or guarantee that the receiving AI will complete the task.

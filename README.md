## 开始使用

打开软件后跟随内置引导，连接自己的 AI 工具账号，再选中文字试一次优化。

0.5.1：新增 Claude Code 连接方式（软件内一键安装、登录与检查），Qwen Code、Kimi Code（实验性）；修复“Skill 协同优化”找不到 Skill，并支持 Claude、Gemini 等工具的 Skill 目录。0.5.0 起：用 API 密钥直接连接 OpenAI、Gemini、Claude、DeepSeek、通义千问、Kimi 等，无需安装 CLI。0.4.16 起：应用内一键更新，Mac 升级保留辅助功能权限。0.4.15 起：内置安装与 AI CLI 调用自动使用系统代理，“测试当前模型”更准确，结果框内可再次优化，新增诊断报告。

0.4.11 已支持旧内置模型预设精简与恢复；自建或改过的配置保留。在模型页可“恢复升级前预设”。

当前为测试版。Windows 未进行发布者代码签名，首次下载或运行可能被系统拦截；先核实来源与文件校验，再按安装帮助处理。Windows 0.5.1 已实测从 0.5.0 覆盖安装保留配置与模板（应用内更新机制已于 0.4.16 实测）；DeepSeek API 与 Claude Code 已真实调用；其他 API 厂商只用模拟服务端测试，Qwen Code、Kimi Code 尚未实测；另一台 Windows 的真实账号慢请求仍需现场复测。Mac 0.5.1 使用自建证书签名，未经 Apple 公证，首次打开可能被系统拦截。Mac 0.5.1 已在 Mac M 系列实测从 0.5.0 覆盖升级保留配置与辅助功能权限（无需重新授权）；其他输入应用和 macOS 版本尚未逐一验证。首次使用或更新后，请按应用内提示检查辅助功能权限。

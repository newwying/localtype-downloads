## 开始使用

打开软件后跟随内置引导，连接自己的 AI 工具账号，再选中文字试一次优化。

0.4.16：新增应用内一键更新（每天最多检查一次，可关闭；确认后自动下载、校验签名、安装并重启）；Mac 改用固定证书签名，此后升级保留辅助功能权限，从 0.4.15 升级时会弹出“一键重新授权”卡片；设置保存期间禁用“界面大小”，诊断报告补充 AGY 失败说明。0.4.15 起：内置安装与 AI CLI 调用自动使用系统代理，“测试当前模型”更准确，结果框内可再次优化，新增诊断报告。

0.4.11 已支持旧内置模型预设精简与恢复；自建或改过的配置保留。在模型页可“恢复升级前预设”。

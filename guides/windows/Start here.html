What Localtype does

Localtype turns selected text into clearer AI instructions. Select a draft in another application, optimize it, review the result, then copy it or replace the selection. You decide when and where to send the result.

It uses your installed Codex or Google Antigravity (AGY) CLI and your account or model service. AI access, usage limits and charges depend on that service. Localtype does not include speech input. You can use text produced by a separate dictation tool.

This guide works offline. Installing AI tools and using network-backed models require a connection. Text capture, replacement and undo depend on the host application; test with disposable text first.

Choose English in the application's language setting if needed. Automatic language uses Chinese on Chinese systems and English on other systems. Your own text, template bodies, paths, model IDs and history are preserved when you change language.

New optimized results follow the interface language by default: English in the English interface and Simplified Chinese in the Chinese interface. An output language explicitly requested in your draft takes priority. Switching languages does not translate existing results or history.

1. Check your computer and package

Open Start > Settings > System > About. This package is for x64 Windows. If System type says ARM, ask your distributor for a compatible package.

Package platform: Windows-x64. Installer: Localtype-0.4.15-Windows-x64-Setup.exe. Compare the installer's SHA-256 with SHA256SUMS.txt from your trusted distributor. A matching checksum checks file integrity; it does not by itself establish that the distributor is trustworthy.

2. Extract the ZIP before installing

Right-click the ZIP in Downloads > Extract All > Extract. Open the extracted folder, then run the included .exe installer.

Keep the README and checksum list with the package. Do not run the installer from the ZIP preview.

Windows protected your PC / an uncommon download

Edge's uncommon-download warning and Windows SmartScreen's launch warning are separate checks. Check the distributor and SHA-256 first. For a package you trust, you can choose More info > Run anyway if Windows offers it. If an organization policy blocks the app or requires an administrator, contact that administrator. Do not disable security software.

Microsoft: Edge SmartScreen · Microsoft: Windows SmartScreen reputation

3. Finish installation and launch

The EXE installer offers an English or Simplified Chinese language selector. MSI packages use their build language instead of this selector; choose the matching language package. Follow the wizard; keep the default location unless you have a reason to change it. If the installer needs WebView2, keep your connection available until it finishes. Launch Localtype from Start. If only the tray icon is visible, use it to show the floating window.

Windows text capture and replacement

Select disposable text in a normal, non-elevated editor and try Optimize. Windows does not use the Mac Accessibility permission switch. Apps running at a different privilege level and some editors may block simulated input. If capture fails, retry in a plain text editor and include the host app's name in your feedback; do not assume every host supports replacement.

Connect one AI tool

Open Settings > Model profiles from the floating window's gear. Find an installed AI CLI and select the candidate you want. If none is installed, use Install Codex CLI or Install AGY CLI. Open the official installation guide beside the button if you need platform instructions. Log in, check the status, save the model profile and make it active.

Use one route; you do not need to install both. Existing CLI installations and account settings can be reused. Finding or installing a CLI does not reset your saved Localtype profiles or clear CLI credentials.

Automatic installation failed

Read the reason beside the button and retry only after addressing it. Open the troubleshooting details and copy them for feedback. You can open or copy the official installation URL. Use the manual fallback below only when needed, rather than overwriting a working installation.

Open a terminal

From Start, open Windows PowerShell without administrator mode. After installing a CLI, close old terminals and open a new PowerShell from Start. Existing terminals do not automatically inherit PATH changes; CMD may not read a PowerShell profile.

Route A: Install Antigravity CLI

Run only if you chose AGY and it is not installed

irm https://antigravity.google/cli/install.ps1 | iex
Read the official AGY installation instructions

Route A: Check the version

Run in a newly opened terminal

agy --version

A version number confirms that the command can start. Installing only the Antigravity desktop application does not necessarily install the CLI.

Route A: Sign in

Start AGY and follow its sign-in prompts

agy

Complete Google account sign-in in the browser if prompted, then return to the terminal. Back in Localtype, check AGY CLI and try an optimization to confirm model access. A runnable CLI alone does not confirm account access or network connectivity.

Find the CLI and resolve path problems

After installation, reopen the terminal and repeat the version check. In Model profiles, find installed tools again and choose the actual executable path. Do not replace a working installation just because a stale terminal cannot find it.

AGY's official default Windows location: check it if needed

& "$env:LOCALAPPDATA\agy\bin\agy.exe" --version

Find the installed Codex path in PowerShell

(Get-Command codex -ErrorAction Stop).Source
Download, login or connection still fails

Check your network, proxy and the selected account. Localtype uses your system proxy automatically (for example a proxy app's “System Proxy” mode); if it still fails, make sure the proxy app is running. Restart Localtype after changing proxy settings. Share diagnostic details without passwords, tokens or login files.

Save and activate your model profile

By default Localtype inherits the CLI's model and reasoning settings. Save the profile, then set it as current. Reopen Model profiles to check that the executable path and inheritance choices remain saved.

An upgrade simplifies unchanged built-in presets to Antigravity and Codex while retaining profiles you created or edited. If needed, use the model page's option to restore pre-upgrade presets and confirm it; conflicting old profiles are restored as separate copies.

1. Select a draft

Paste this fictional sample into a blank text document, then explicitly select the whole paragraph. On Mac, Sublime also requires an active selection.

Practice text

Research a shared task app for two people to manage groceries, chores and travel preparation. Compare phone and desktop support, explain the limits of the free plans, and recommend an option with links to original sources.
No text was captured

Select the text again in a plain text editor. On Mac, verify Accessibility permissions. If it still fails, report the host application's name and the error, with private text removed.

2. Optimize and review

Keep the original text selected and click Optimize in the floating window. Cancel stops the current request. Review the preview for missing constraints or added assumptions before using it.

Timeout, model access or network failure

Check the chosen CLI, account and model in its own terminal. Confirm that the account whose quota you checked is the one Localtype uses. Select the original text again before retrying. Unknown login status needs diagnosis; it is not proof that you are signed in.

3. Copy the result

Click Copy in the preview, switch to your AI tool and press Ctrl+V. Review it, then send it yourself. Choose any research or execution mode in the receiving tool separately.

More ways to use Localtype

The following features are optional. Start with copying until you know how your editor handles selection and simulated input.

Replace the selected text

After selecting text and optimizing it, click Replace in the preview. Keep the source window and original text unchanged while the request runs. Verify the result in the source app.

The result was appended instead

Stop clicking Replace. Use Copy to keep the result, then report the host application and what happened. Use disposable text for further testing.

Undo a replacement

Use Undo in the same preview after replacement. Localtype stops before writing if it cannot verify the current text. If it says undo was sent but the outcome could not be confirmed, inspect the source app and, if needed, use that app's own undo. Do not repeatedly overwrite the text.

Templates, modes and language

Use the left and right arrows in the floating window to change templates. Edit templates and their order in Settings > Prompt templates. Your own template bodies are not automatically translated when you change the interface language.

Standard, Plan and Goal are single-pass prompt optimization modes. Plan structures steps and checks; Goal emphasizes the authorized outcome and completion conditions. These modes change the output prompt. They do not automatically switch the receiving AI harness's mode, run the task or grant additional permission.

Optional: Skill context

Choose Skill-assisted optimization when you want to refer to an existing instruction file. Replace the sample path with your own file. Localtype uses the file as read-only context for optimization; it does not execute the task in it. Only include content you are comfortable sending to your configured AI service.

Example: replace this path first

Use [My Skill](C:/Users/your-name/.codex/skills/my-skill/SKILL.md) as context to improve this request: ...
The Skill file cannot be found

Check that the referenced file exists, or return to General optimization and select your draft again.

Local history and privacy

Open Settings > History to enable local saving and view saved results. Content from before saving was enabled cannot be recovered retroactively. Review your history retention settings. Local history is separate from text sent to your configured AI service; offline storage does not make model requests offline.

Upgrade while keeping your settings

Finish or cancel an optimization, then quit Localtype from its tray menu. Install the newer package for the same platform. On Windows follow the upgrade wizard; keep any option to delete application data unchecked. On Mac replace the app in Applications. You do not need to delete your configuration, history or CLI account files.

Reopen the app and check the language, current model, templates and history. Existing guidance completion state is retained; use Help & feedback to reopen the step-by-step guide. On Mac, restart once before trying the permission repair steps. If you must roll back, use the previous trusted installer and preserve user data rather than clearing it.

Uninstall the application

Quit Localtype first. On Windows open Settings > Apps > Installed apps, find Localtype and choose Uninstall. If the uninstaller offers to delete application data, leave it unchecked to retain your settings and history. Select it only if you intentionally want to remove that data.

Localtype and your AI CLI are separate installations. Uninstalling Localtype does not mean your Codex or AGY account has been signed out or its installation removed. Manage those tools with their own instructions.

Example: a rough idea becomes a reviewable task

Fictional illustration, not a real model result: “Fix the mobile booking button; it is hidden by the bottom bar. Sometimes submitting twice creates two bookings. Keep the desktop layout working.”

A clearer request: “Investigate the mobile booking button being covered by bottom navigation. Preserve the working desktop layout. Reproduce the missing submission feedback and possible duplicate bookings before choosing a fix. Verify mobile and desktop success, rapid clicks, slow network and failure cases. Report the cause, changes, tests and remaining gaps.”

Optimization should retain uncertainty and your constraints. It cannot prove a diagnosis or guarantee that the receiving AI will complete the task.

## 开始使用

打开软件后跟随内置引导，连接自己的 AI 工具账号，再选中文字试一次优化。

0.4.11：AI CLI 安装失败后，按提示重试，或点击“查看排错详情”→“复制排错详情”反馈，无需运行排错脚本。升级时，未修改的旧内置模型预设精简为 Antigravity、Codex 两项，并跟随 CLI 设置；自建或改过的配置保留。在模型页可“恢复升级前预设”，找回此次调整的旧项。模板、历史及引导进度保留。

当前为测试版。Mac M 系列采用 ad-hoc 签名，未进行 Apple Developer 签名和公证，首次打开可能受到系统拦截。本轮已核验 Mac 权限及文本优化，复制、替换与撤销经用户实机确认；其他输入应用尚未逐一验证。Windows 最终安装向导及真实覆盖升级人工回归仍待确认。
